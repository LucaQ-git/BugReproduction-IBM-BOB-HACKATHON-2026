## 4. Root Cause Analysis

**File:** `src/cart.fixture.js`, lines 13–17.

```js
// src/cart.fixture.js  lines 13–16
function calculateTotal(items, discountPercentage) {
  let subtotal = items.reduce((sum, item) => sum + item.price, 0);
  let discount = (subtotal * discountPercentage) / 100;
  return subtotal - discount;
}
```

Three distinct defects:

| Defect | Code path | Business rule violated |
|--------|-----------|------------------------|
| **NaN propagation** | `discountPercentage` is `undefined` → `subtotal * undefined = NaN` → `NaN / 100 = NaN` → returns `NaN`. Also triggered when any `item.price` is missing/NaN. | Rules 3, 4, 7 |
| **Negative total** | When `discountPercentage > 100`, `discount > subtotal`, so `subtotal - discount < 0`. No clamp applied. | Rule 2 |
| **No input validation** | No guard for `NaN`, `Infinity`, `undefined` discount or missing/negative item prices — all silently propagate into arithmetic. | Rules 4, 5, 6, 7, 8 |

The core arithmetic on line 14 (`subtotal * discountPercentage`) and line 16 (`return subtotal - discount`) has no guards whatsoever, violating Rules 2, 3, 4, 5, 6, 7, and 8 simultaneously.
