# BugRep-AI

> Automated bug reproduction and regression patch generator powered by **IBM Bob 2.0**.

## What It Does

Given a plain-English bug report, BugRep-AI:

1. **Parses** the bug report and business-rule documentation (IBM Bob Document Understanding).
2. **Writes** a strict unit-test that asserts the expected correct behaviour.
3. **Runs** the test against the broken implementation → **RED** (bug reproduced).
4. **Applies** an implementation patch generated by IBM Bob's agent.
5. **Re-runs** the test suite → **GREEN** (regression fixed, assertions unchanged).

## Prerequisites

- **Node.js** ≥ 18
- **npm** ≥ 9

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run the full BugRep-AI workflow
node orchestrator.js
```

You will see the following output sequence in your terminal:

```

📄 Step 1: Document Understanding & Context Loaded.
🔍 Step 2: Bob Subagents executing...

🔴 Step 4: Running test suite... (FAILS — bug reproduced)
🔧 Step 5: Bob Agent applying implementation patch...
🟢 Step 6: Re-running test suite... (PASSES — regression fixed)

🎉 SUCCESS
```

## Bobcoin Compliance

Every team member must capture their **task session summary** from Bob IDE:

1. Open **Tasks** in the Bob IDE chat panel.
2. Select your task → click the task header to view session consumption.
3. Screenshot as **PNG** and save to `/bob_sessions/` using the naming convention:

```
bob_sessions/<member>_task<nn>_<short_description>.png
```

## Test Integrity Policy

The test file (`src/cart.test.js`) uses **strict assertions** (`toBe`, `toBeGreaterThanOrEqual`).
IBM Bob is explicitly instructed **never** to weaken these assertions to make a failing test pass.
The only valid fix is a correct implementation change in `src/cart.js`.
