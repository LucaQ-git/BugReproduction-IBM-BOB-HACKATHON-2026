What a Bob Session Summary Looks Like & How to Capture It
  1. In Bob IDE, open the Tasks panel in the left sidebar.
  2. Select the task you just ran (e.g. "Bug Analysis" or "Patch Generation").
  3. Click the task title / header at the top of the task detail view.
  4. A session summary card appears showing the fields below.
  5. Press Print Screen or use your OS snipping tool, save as .png.
  6. Drop the file in /bob_sessions/ named e.g. alice_task01_bug_analysis.png.
